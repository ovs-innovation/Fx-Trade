# FXTrade Consulting Pvt. Ltd. — Web Application

Corporate website and digital platform for **FXTrade Consulting Pvt. Ltd.**, providing specialized corporate finance, domestic and international trade finance, treasury advisory, debt syndication, and structured financial solutions.

---

## 🚀 Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router DOM (v7)
- **Styling**: Vanilla CSS (modular design tokens & custom design system)
- **Icons**: Lucide React
- **Animations & Micro-interactions**: Framer Motion
- **Build Tool**: Vite

---

## 📁 Project Structure

```text
FXTRADE/
├── public/                 # Static assets
├── src/
│   ├── assets/             # Images, photography & media
│   ├── components/         # Reusable UI components
│   │   ├── common/         # Buttons, containers, modals
│   │   ├── layout/         # Header, Footer, PageShell, MobileMenu
│   │   └── services/       # Service cards & widgets
│   ├── data/               # Structured data & content
│   ├── pages/              # Page routes (Home, About, Services, Contact, etc.)
│   ├── services/           # Service & form handlers
│   ├── App.jsx             # Route definitions
│   ├── index.css           # Global design system & tokens
│   └── main.jsx            # Application entrypoint
├── index.html              # HTML shell
├── package.json            # Dependencies & npm scripts
└── vite.config.js          # Vite configuration
```

---

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The app will run locally at `http://localhost:5173/`.

### 3. Production Build
```bash
npm run build
```
